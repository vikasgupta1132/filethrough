Stop switching between upload forms and file tools

Websites often impose different file formats, size limits, and image dimensions. FileThrough reads available requirements from the upload page and prepares the selected file before it is returned to the upload field.

The goal is simple: fewer manual conversions, fewer failed uploads, and less repetitive file preparation.

What FileThrough Does

Current capabilities of the extension

1

Detects upload requirements

FileThrough examines file inputs and nearby page text for supported formats, file-size limits, and image or PDF dimensions.

2

Prepares supported files

Images and PDFs can be transformed when the detected requirements call for it.

  • Resize images or PDF pages
  • Convert supported image formats
  • Compress images and PDFs to size limits
3

Validates before replacement

The processed file is checked again against the detected requirements before FileThrough replaces the selected file in the upload input.

4

Handles dynamic upload fields

FileThrough watches for file inputs added after the page has loaded, which is common in modern web applications.

5

Supports PDF processing

PDF files can be resized or compressed when the detected upload requirements require PDF processing.

6

Configurable options

The extension includes an Options page for enabling automatic processing, setting a maximum file-size preference, and defining transformation plans.

How It Works

The current processing pipeline is designed to keep the workflow automatic.

1

Detect

Finds file-upload inputs, including inputs added dynamically.

2

Parse

Reads supported format, size, and dimension requirements from the page.

3

Inspect

Examines the selected file before deciding whether a transformation is necessary.

4

Transform

Converts or resizes the file when required, then compresses it when size constraints demand it.

5

Validate

Checks the final file again against the detected requirements.

6

Replace

Places the validated processed file back into the upload input so the website can receive it.

Local-first processing

Your files are processed in the browser

Files are processed locally

FileThrough performs its core transformations in the browser rather than sending files to a FileThrough processing server.

Only the extension's settings are stored

Extension preferences and transformation rules are stored through browser extension storage.

Open source

The extension source is publicly available for inspection and contribution.
