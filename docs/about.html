About FileThrough

Making repetitive file preparation easier when websites impose upload requirements.

Our Mission

FileThrough was created around a simple problem: websites often require specific file formats, dimensions, or size ranges, forcing users to leave the page and prepare files manually.

FileThrough is designed to read supported upload requirements from the page and prepare selected images and PDFs locally in the browser before returning the processed file to the upload field.

Privacy First

Core file processing happens locally in the browser. FileThrough is not designed around uploading users' files to a FileThrough processing server.

Open Source

The extension is open source under the MIT License. The source code is available on GitHub so developers can inspect the implementation and contribute improvements.

View the GitHub Repository

Current Product Scope

FileThrough currently focuses on automatic preparation of supported image and PDF uploads. It is not a general-purpose image editor or PDF editor, and features such as OCR, annotations, batch editing, and a full editing workspace are not part of the current extension.
